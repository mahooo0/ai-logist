## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Added zero-length buffer guard in `verifyElevenLabsSignature`**
- **Found during:** Task 2 (writing signature.ts from RESEARCH §Block 3)
- **Issue:** RESEARCH §Block 3 verbatim has `Buffer.from(provided, 'hex')` with no error handling. `Buffer.from('not_valid_hex', 'hex')` returns a zero-length buffer rather than throwing; `expectedBuf.length === providedBuf.length` is then `false` so the early-return catches that case — BUT if both `provided` and `expected` happened to be empty strings (e.g. empty secret + empty body), `timingSafeEqual(zero, zero)` returns `true` (false positive accepting any signature for the empty-secret case).
- **Fix:** Added `if (expectedBuf.length === 0 || providedBuf.length === 0) return false;` BEFORE the length-equality check. Defense-in-depth — production paths will never hit empty-secret (requireVoiceConfig guards), but the helper is now safe to call directly with any input.
- **Files modified:** `apps/api/src/channels/voice/signature.ts`
- **Verification:** 5 voice-signature.test it() blocks pass; bare-hex + tampered + wrong-secret + missing-header all return false.
- **Committed in:** `6757e4b` (Task 2)

**2. [Style] Biome wrapped imports in `calls.ts` to multi-line**
- **Found during:** Task 1 (post-write biome check)
- **Issue:** Adding 5+ imports from `drizzle-orm/pg-core` exceeded Biome's line-width budget for single-line import grouping (`import { bigint, index, jsonb, pgTable, text, timestamp, uniqueIndex, uuid }`).
- **Fix:** Ran `pnpm exec biome check --write apps/api/src/config.ts apps/api/src/persistence/schema/calls.ts apps/api/src/persistence/schema/_enums.ts`. Biome reformatted to one-import-per-line shape. Semantics preserved; identical to Plan 03.1-00 / 01-07 / 02-03b lessons.
