### Auto-fixed Issues

**1. [Rule 1 - Bug] TS2742 portability errors on inferred Vitest mock types**
- **Found during:** Task 1 (post-write typecheck)
- **Issue:** `vi.fn().mockResolvedValue(...)` returns a type that references `.pnpm/@vitest+spy@4.1.8/node_modules/@vitest/spy` internal paths. Tsc emits TS2742 when those types are inferred onto exported class properties because the path isn't portable across machines / pnpm hash changes.
- **Fix:** Added explicit `any` type annotations (with `biome-ignore lint/suspicious/noExplicitAny` comment + rationale) on `MockElevenLabsClient.conversationalAi`, `MockTwilioClient.incomingPhoneNumbers`, and `MockTwilioClient.api`. Same trade-off taken by Phase 2 `mock-anthropic.ts`. Plan explicitly authorised this in Task 1 step 1 ("Use `any` only where Vitest's `ReturnType<typeof vi.fn>` makes types unwieldy").
- **Files modified:** `apps/api/tests/_helpers/voice-mock.ts`
- **Commit:** `7475986` (Task 1)
