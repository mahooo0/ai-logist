## Provider Stack
**Auto:** Twilio (~$3/mo number + $0.02/min) + ElevenLabs Starter ($6/mo) + Turbo Conversational AI ($0.10/min). Demo budget ~$15.

## Webhook Architecture
**Auto:** Multiple `/webhook/voice/*` endpoints — one per ElevenLabs tool callback + call-start/end + Twilio status webhooks. HMAC signature verification.

## Tool Adapter Pattern
**Auto:** Voice tool handlers wrap Phase 2 tools (extract-request, nearest-truck, calc-price, create-order, discount). Map ElevenLabs format ↔ Phase 2 tool calls. NO tool duplication.

## Conversation State
**Auto:** Redis key `voice:state:<conversation_id>` (TTL 60 min) holds client_id, lead_id, extracted_fields, matched_truck, quoted_price, lang.

## Language Detection (Voice-specific)
**Auto:** ElevenLabs detects from first phrase (>2s audio), callback `lang-detected` → save to `clients.lang` ONCE (sticky). Skip detection if client.lang already set.

## Price-Lock Protocol
**Auto:** voice `calc-price` writes `quoted_price` to DB BEFORE return; voice `create-order` re-reads from DB inside tx. Same Pitfall #1 closure as Phase 2.

## FSM Concurrency
**Auto:** `pg_advisory_xact_lock(hashtext(conversation_id))` in every voice tool handler.

## Anti-Injection
**Auto:** Structural defense via tool boundaries (no DB access except through tools) + ElevenLabs system prompt with ANTI_INJECTION_PREFIX + post-response price guard.

## Test Strategy
**Auto:** MockElevenLabsClient + MockTwilioClient + 5 local audio fixtures. Real ElevenLabs only gated by `VOICE_TEST_REAL=1` env. UAT-04 = human verification.

## ElevenLabs Agent Configuration
**Auto:** One agent for both RU+UA via Multilingual v2 voice + system prompt rules. Config versioned in `apps/api/src/channels/voice/elevenlabs-agent-config.md`.

## Bootstrap Script
**Auto:** `pnpm voice:setup` — validates env, registers/updates Agent in ElevenLabs, configures Twilio number webhook URL.
